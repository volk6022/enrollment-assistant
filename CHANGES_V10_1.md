# v10.1 — Демонстрация голосового ввода в браузере с использованием Yandex SpeechKit

## Добавлено

- Страница демонстрации в браузере по адресу `/demo`
- Запись с микрофона в браузере с экспортом в WAV
- Процесс загрузки аудиофайлов в форматах `.wav`, `.ogg`, `.mp3`
- Нормализация WAV до PCM16 моно перед SpeechKit STT
- Улучшенный путь локального тестирования без телефонии

## Изменено

- Версия `voice-gateway` -> `10.1.0`
- Демонстрационный режим -> `browser-demo`
- Частота дискретизации TTS по умолчанию в Compose -> `48000`

## Примечания

Эта версия ориентирована на локальное тестирование голосового ввода/вывода через SpeechKit и не требует SIP/RTP-телефонии.

## Исправления в версии 10.2
- Исправлена ​​целостность голосовой сессии при уточнениях
- Добавлены резервный вариант TTS и исправлены некритические ошибки TTS
- Формат TTS в демоверсии SpeechKit по умолчанию изменен на mp3
- Демоверсия в браузере теперь воспроизводит аудио помощника из audio_url или встроенного base64 и отображает ошибки воспроизведения
- Пустой/неудачный STT теперь возвращает запрос на повтор вместо сбоя в диалоге
