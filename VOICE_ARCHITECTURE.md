# Архитектура голосового интерфейса для системы помощи при поступлении

## Сервисы
- `backend`: логическое обоснование, RAG, синтез ответов, политики вызовов.

- `voice-gateway`: SpeechKit STT/TTS, состояние сеанса вызова, кэширование аудио, граница телефонного адаптера.

- `redis`: кратковременное состояние голосового сеанса.

## Основной процесс
1. Телефон/адаптер отправляет вызов на `voice-gateway`
2. `voice-gateway` начинает вызов в `backend` через `/voice/start`
3. Речь звонящего распознается SpeechKit STT
4. Итоговая расшифровка отправляется в `/voice/turn`
5. Backend возвращает `answer`, `voice_answer`, `tts_text`, `handoff_recommended`
6. `voice-gateway` синтезирует `tts_text` с помощью SpeechKit TTS и воспроизводит его
7. При необходимости запускается опциональный `/voice/handoff`

## Текущий путь демонстрации
- `POST /calls/start`
- `POST /calls/{call_id}/turn`
- `POST /calls/{call_id}/recognize-and-answer`
- `POST /calls/{call_id}/handoff`
