# v11.3 — brief-direct answer mechanism

## Что изменено

- Убран приоритет прямых FAQ-ответов: FAQ больше не используется как источник вшитых реплик.
- Добавлен новый механизм **brief-direct answers**: вопрос → intent → search → structured extraction → короткий ответ.
- Расширена карта intent'ов под частые сценарии приемной комиссии: программы по форме обучения, экзамены, гражданство, здоровье, возраст, платное обучение, общежитие, второе высшее, перевод, ускоренное обучение и др.
- Добавлены новые extractors:
  - `ProgramsByFormExtractor`
  - `ExamsInfoExtractor`
  - `PolicyExtractor` для yes/no и policy-вопросов
- Добавлен `BriefAnswerComposer`, который переформулирует извлеченные факты в короткий и прикладной ответ без цитат и фраз вроде «по найденным фрагментам».
- Улучшены search profiles и query expansions для частых вопросов.
- Ответы должны быть короче, конкретнее и ближе по стилю к ответам сотрудника приемной комиссии.
