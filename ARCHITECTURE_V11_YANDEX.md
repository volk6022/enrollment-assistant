# v11 architecture: Yandex Cloud / AI Studio

## Цели

В версии 11 механизм обработки ответов перенесен с локального RAG, ориентированного на Ollama + fastembed + Qdrant, на конвейер, ориентированный на Яндекс:

1. Классификация намерения вопроса
2. Поиск документов в хранилище векторов AI Studio / Поиск файлов
3. Извлечение структурированных фактов через структурированный вывод YandexGPT
4. Формирование окончательного текстового ответа и короткого `tts_text`

Голосовой слой остается на базе Yandex SpeechKit.

## Основные принципы

- SpeechKit по-прежнему отвечает за STT/TTS.

- Бэкенд управляет бизнес-логикой и состоянием диалога.

- AI Studio обрабатывает:

- YandexGPT Lite для облегченной классификации/переписывания
- YandexGPT Pro для извлечения структурированных данных
- API встраивания / хранилище векторов / поиск файлов для получения данных
- Устаревший RAG остается доступным в качестве резервного механизма.


## Переключение среды выполнения

Установка переменной окружения:

```env
BACKEND_ENGINE=auto
```

Бэкенд будет использовать `yandex_v11`, если установлены все следующие параметры:

- `YC_FOLDER_ID`
- `YC_AI_API_KEY`
- `YANDEX_VECTOR_STORE_ID`

В противном случае будет использоваться устаревший RAG.

Принудительное указание движка:

```env
BACKEND_ENGINE=yandex_v11
```

## Новый пайплайн

### 1. Классификация намерений

`backend/app/intents/classify.py`

- Начальная загрузка на основе правил из существующего проекта
- Дополнительное уточнение классификатора Яндекса

### 2. Переписывание запросов

`backend/app/search/query_rewrite.py`

- Генерирует дополнительные поисковые запросы для одного и того же вопроса пользователя
- Использует YandexGPT Lite, если доступен

### 3. Поиск в векторном хранилище

`backend/app/search/vector_store_client.py`

- Выполняет поиск в настроенном векторном хранилище AI Studio
- Возвращает нормализованные совпадения (`SearchHit`)

### 4. Типизированное извлечение

`backend/app/extraction/*`

Существуют специальные экстракторы для:

- `min_scores`
- `documents`
- `apply`
- `without_ege`
- `benefits`

Сначала они пытаются получить структурированный вывод через YandexGPT Сначала Pro, а затем возврат к эвристическому извлечению.

### 5. Создание ответа

`backend/app/generation/answer_builder.py`

- создает ответ, понятный человеку
- создает компактный `tts_text`
- добавляет цитаты и метаданные

## Новые переменные конфигурации

```env
YC_FOLDER_ID=
YC_AI_API_KEY=
YANDEX_VECTOR_STORE_ID=
YANDEXGPT_LITE_MODEL=yandexgpt-lite/latest
YANDEXGPT_PRO_MODEL=yandexgpt/latest
YANDEX_EMBEDDING_MODEL=text-search-query/latest

```
