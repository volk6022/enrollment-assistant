# Изменения в версии 7

- Переработан процесс поиска с учетом гибридного конвейера, используемого в производственной среде: варианты запросов, поиск по нескольким запросам, объединение запросов, переранжирование и ответы, основанные на доказательствах.

- Упрощено генерирование ответов для рискованных намерений: ответы основаны на извлеченных доказательствах, а не на громоздких шаблонах свободной формы.

- Ужесточены правила фильтрации и исключения программ/тем для нерелевантных федеральных законов и дополнительных документов.

- Сохранено поведение, основанное на поиске ответов, но теперь ответы воздерживаются, когда доказательства слабы, вместо того, чтобы выдумывать конкретные примеры.
