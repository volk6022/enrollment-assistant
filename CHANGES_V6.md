# Изменения в версии 6

- Добавлена ​​более жесткая фильтрация по области действия программы, чтобы предотвратить проникновение источников, содержащих только дополнительные материалы, в общие ответы на вопросы о приеме.

- Добавлен более безопасный структурированный синтез ответов для рискованных намерений: min_scores, documents, apply, without_ege.

- Усилено исключение фрагментов, связанных со здоровьем/ВВК, хранением записей и достижениями, для несвязанных вопросов.

- Объединены метаданные предполагаемой темы с метаданными реестра, чтобы локальные правила и порядок приема сохраняли актуальность min_scores/экзамена.

- Версия API повышена до 6.0.0.
