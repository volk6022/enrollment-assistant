# Изменения в версии 9

- Исправлена ​​передача `section_path` в конструкторы ответов.

- Добавлена ​​локализованная сборка BLOB-объектов с учетом разделов вокруг одного и того же раздела/близлежащих точек.

- Усилена фильтрация по намерениям для `documents`, `apply`, `min_scores`, `without_ege`.

- Добавлены типизированные вспомогательные функции для извлечения оценок по темам, списков документов, методов применения и категорий без EGE.

- Снижено загрязнение от несвязанных близлежащих точек внутри одного и того же исходного документа.
