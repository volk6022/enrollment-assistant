# База знаний приёмной комиссии ДВЮИ МВД (компилированная)

Чистый, дедуплицированный и непротиворечивый свод знаний для голосового RAG-ассистента,
собранный из пакета нормативных документов (НПА) по **паттерну Karpathy**: `raw/` —
первоисточники правды, `wiki/` — компилированное изложение, пригодное для качественного
чанкинга и retrieval.

## Структура

```
knowledge-base/
├── README.md              # этот файл
├── schema/
│   └── compile-rules.md   # правила компиляции raw → wiki (формат, фидельность, иерархия)
├── raw/
│   └── README.md          # указатель на первоисточники (НПА не дублируются)
├── wiki/                  # компилированные тематические заметки (то, что индексируется)
│   ├── 00-context.md      # контекст проекта: аудитория, темы, границы
│   ├── INDEX.md           # навигация + карта «вопрос → заметка»
│   └── 01..10-*.md        # 10 тематических заметок
└── _staging/              # промежуточные дайджесты и срезы источников (провенанс)
```

## Как это собрано

1. **Контекст и правила** (`00-context.md`, `schema/compile-rules.md`) — написаны вручную.
2. **Первичная переработка** — локальная модель **Qwen3.5-9B** (dispatch-local, llama.cpp)
   переработала каждый раздел Правил приёма и каждый профильный НПА в дайджест атомарных
   утверждений с ссылками на пункты (`_staging/*.md`).
3. **Сборка и контроль качества** — сведение дайджестов в тематические заметки `wiki/`,
   нормализация формата, восстановление wikilinks, разрешение противоречий и **сверка
   номеров пунктов с первоисточником**.

## Что вошло (scope v1)

Правила приёма ДВЮИ МВД 2025 (№ 1093) — как основа, плюс профильные НПА, к которым
Правила отсылают: Приказ МВД № 370 (медосвидетельствование), Приказ МВД № 620 (состояние
здоровья), Приказ МВД № 568 (отчисление/восстановление/перевод), Приказ Рособрнадзора
№ 876 (сроки ЕГЭ), Указ Президента № 268 (СВО), Постановление Правительства № 2122
(адъюнктура). Полный список — `raw/README.md`.

## Проверено при сборке

- Номера пунктов особых прав/льгот (п. 36–48) и зачисления (п. 96–110) **сверены дословно**
  с текстом Правил приёма — совпадают.
- Исправлена ошибка локальной модели: категория годности **Г — это п. 6.4** (не 6.5).
- Удалена галлюцинация «ЕГЭ не ниже 75 баллов» для олимпиадников; в источнике (п. 48) —
  «не ниже количества баллов, установленного Институтом».

## Известные ограничения (отмечены `[ТРЕБУЕТ ПРОВЕРКИ]` в тексте)

- **Числовые нормативы физподготовки** (секунды/повторы по упражнениям) в v1 не сведены:
  исходный Приказ МВД № 44 в основном регулирует профессиональную подготовку кадров, а не
  вступительный экзамен. Нужна отдельная выверка нормативной таблицы.
- **Перечень предметов ЕГЭ**: возможен version-skew внутренней «приоритетности» с федеральным
  перечнем (Приказ Минобрнауки № 820, действует с 01.03.2025). Приоритет — у федерального.
