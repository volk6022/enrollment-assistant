# Правила компиляции базы знаний (raw/ → wiki/)

Инструкции для LLM, которая перерабатывает исходные НПА (`raw/`) в чистые заметки
знаний (`wiki/`). Применяются и локальной моделью (dispatch-local), и при финальной
сборке.

## Формат заметки-дайджеста

Каждая заметка `wiki/` — набор **атомарных утверждений**. Одно утверждение = один факт,
пригодный для короткого голосового ответа. Формат утверждения:

```
- **<короткое ясное утверждение официальным, но человеческим языком>**
  <при необходимости 1–2 уточняющих предложения; дословно сохранены числа, даты, термины>
  — *Источник: <короткое имя документа>, <пункт/статья>.*
```

## Жёсткие правила

1. **Не выдумывать.** Только то, что есть в источнике. Незнакомое — оставить как есть.
2. **Сохранять дословно:** числа, даты, проценты, сроки, аббревиатуры (ЕГЭ, СВО, ВВК,
   СНИЛС, СПО), названия документов и **номера пунктов/статей** — это якорь цитаты.
3. **Убирать канцелярит и самоповторы.** «Определяют условия приема, порядок проведения…»
   → по существу. Разворачивать вложенные исключения в понятные формулировки.
4. **Оставлять только релевантное абитуриенту.** Внутриведомственная машинерия
   (делопроизводство, отчётность, служебные характеристики) — выбрасывать.
5. **Каждое утверждение снабжать ссылкой** на исходный документ и пункт.
6. **Помечать неоднозначности.** Если источник противоречив или редакция под вопросом —
   `[ТРЕБУЕТ ПРОВЕРКИ: …]`, не сглаживать молча.
7. **Не смешивать темы** из разных документов внутри одного утверждения.

## Иерархия юридической силы

ФЗ → Указ Президента → Постановление Правительства → приказ министерства → Правила приёма.
Если утверждения расходятся — приоритет у акта более высокой силы и более поздней редакции;
расхождение фиксировать явно.

## Роли исполнителей

- **dispatch-local (Qwen3.5-9B)** — первичная переработка одного раздела/документа в
  дайджест по формату выше (файлы в `_staging/`).
- **Claude (сборка)** — сведение дайджестов в тематические заметки `wiki/`, разрешение
  противоречий, простановка frontmatter, wikilinks, `INDEX.md`.
