# raw/ — первоисточники

Компилированная база в `wiki/` собрана из **исходных НПА** (первоисточники правды).
Сами документы физически лежат в корпусе проекта и не дублируются здесь во избежание
рассинхрона:

- Исходные `.docx`: `data/npa/2025/`
- Извлечённый текст (`.txt`), по которому шла компиляция: `experiment-docx-processing/out/txt/`

При любом сомнении в формулировке `wiki/` — сверяться с этими файлами по номеру пункта,
указанному в ссылке `— Источник: <документ>, п. <номер>`.
