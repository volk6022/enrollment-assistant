## 🏃 Физическое испытание

### Общие положения
- Оценивается оценками **«зачтено» / «не зачтено»**
- Проводится Институтом самостоятельно
- Организуется в форме выполнения контрольных упражнений
- Утверждено приказом МВД России от 2 февраля 2024 г. № 44

### Минимальный балл
- **3 балла** (не менее 1 балла по каждому контрольному упражнению)

### Критерии оценки
Устанавливаются в зависимости от категории годности к службе:

| Категория годности | Для специальностей |
|-------------------|-------------------|
| А, Б | 40.03.02 — Оперативно-розыскная деятельность |
| А, Б, В | 40.03.02 — Административная деятельность полиции |
| | 40.05.01 — Предварительное расследование |
| | 40.02.02 — Административная деятельность полиции |

## 📊 Физическая подготовка (дополнительное вступительное испытание)

### Упражнения и нормативы

#### Мужчины
1. Подтягивание на перекладине
2. Бег 100 м
3. Бег (кросс) на 1000 м

#### Женщины
1. Силовое комплексное упражнение
2. Бег 100 м
3. Бег (кросс) на 1000 м

### Шкала оценивания
- **Максимальный балл: 3** (по 1 баллу за каждое упражнение)
- Для допуска к следующему упражнению достаточно **1 балла**

### Критерии прохождения
- **Успешное выполнение**: 3 балла (1 балл за каждое упражнение)
- **Не пройдено**: 0 баллов по одному из упражнений
- При 0 баллах по одному упражнению: кандидат не допускается к дальнейшим упражнениям и к конкурсу

## 📌 Основные правила

- Шкала оценивания и минимальные баллы устанавливаются **до начала приема**
- Минимальное количество баллов **не может быть изменено** в ходе приема
- Результаты ЕГЭ 2021–2025 годов принимаются
- Для отдельных категорий: возможен выбор между ЕГЭ и собеседованием
