# Дайджест положений Приказа МВД России № 177 от 31.03.2025 (продолжение)
## Апелляции и оформление решений для абитуриентов

---

## I. СРОКИ (Deadlines)

| Пункт | Содержание срока |
|-------|------------------|
| **89** | Апелляция подаётся **в день объявления результатов** или **в течение следующего рабочего дня** |
| **90** | Апелляция рассматривается **не позднее следующего рабочего дня** после подачи |
| **86.1** | Результаты устных испытаний размещаются **в день проведения** |
| **86.2** | Результаты письменных/смешанных форм — **не позднее следующего календарного дня** |
| **86.3** | Доп. испытание по физической подготовке — **не позднее следующего дня** |
| **114** | Распорядительный акт о зачислении издаётся **не позднее 10 рабочих дней** до начала учебного года |
| **116** | Выписки из приказа направляются комплектующим органам **в течение 5 рабочих дней** |
| **118** | Лицо подлежит отчислению, если не приступило к обучению **в течение 10 рабочих дней** с начала занятий |

---

## II. ПОРЯДОК ПОДАЧИ АПЕЛЛЯЦИИ (Procedure)

| Пункт | Содержание |
|-------|-------------|
| **88** | Право подать апелляцию имеют: кандидат, **родитель** (для несовершеннолетних), или **представитель по доверенности** |
| **89** | Апелляция адресуется **председателю апелляционной комиссии** |
| **91** | Апелляция **не является пересдачей** вступительного испытания |
| **95** | Допускается проведение апелляции **с использованием дистанционных технологий** при идентификации |

---

## III. ПРАВА ЗАЯВИТЕЛЯ (Applicant Rights)

| Пункт | Право |
|-------|-------|
| **75.1** | Уведомление о применении **технических средств аудиовидеофиксации** (для защиты прав) |
| **79** | **Однократная сдача** каждого вступительного испытания |
| **81** | Допуск к сдаче в **другой группе или резервный день** по уважительной причине (болезнь, иные обстоятельства с документальным подтверждением) |
| **86** | Размещение результатов с использованием **уникального кода** |
| **87** | Ознакомление со своей работой **в день объявления результатов** или **в течение следующего календарного дня** |
| **93** | Право присутствовать при **рассмотрении апелляции** |
| **94** | Для несовершеннолетних — право присутствия **родителя** или **представителя по доверенности** |
| **104** | Получение решения **электронной почтой** при дистанционном формате |

---

## IV. ОФОРМЛЕНИЕ РЕШЕНИЙ АПЕЛЛЯЦИОННОЙ КОМИССИИ (Resolution Formatting)

| Пункт | Содержание оформления |
|-------|----------------------|
| **99** | Решение об **оставлении оценки без изменения**, её **изменении** или **аннулировании** |
| **100** | При аннулировании оценки — предоставление возможности пройти испытание в **резервный день** |
| **101** | Решение доводится до сведения кандидата **в оформленном протоколе** |
| **102** | Факт ознакомления заверяется **личной подписью** кандидата, родителя или представителя |
| **103** | При отказе/невозможности ознакомиться — составляется **акт** |
| **97** | В случае разногласий — решение принимается **большинством голосов** |
| **98** | При равенстве голосов — решающим является голос **председателя** апелляционной комиссии |

---

## V. ОСОБЫЕ УСЛОВИЯ (Special Conditions)

| Пункт | Содержание |
|-------|-------------|
| **96** | Использование **аудиовидеоинформации** с технических средств фиксации при рассмотрении апелляции |
| **115** | Кандидат, забравший документы после акта о зачислении — **отчисляется** из образовательной организации |

---

## VI. РЕЗЮМЕ СРОКОВ ДЛЯ АБИТУРИЕНТА

```
ДЕНЬ ОБЪЯВЛЕНИЯ РЕЗУЛЬТАТОВ:
  ├─ Ознакомление с работой: в этот день ИЛИ в течение 1 рабочего дня (п. 87)
  ├─ Подача апелляции: в этот день ИЛИ в течение 1 рабочего дня (п. 89)
  └─ Рассмотрение апелляции: не позднее следующего рабочего дня (п. 90)

ДО НАЧАЛА УЧЕБНОГО ГОДА:
  └─ Распорядительный акт о зачислении: не позднее 10 рабочих дней до начала (п. 114)
```
