# Локальное тестирование голосового ввода и вывода через Yandex SpeechKit

## Что есть в проекте

В проект добавлен отдельный сервис `voice-gateway`, который позволяет без телефонии:

1. записать вопрос голосом в браузере;
2. распознать его через Yandex SpeechKit STT;
3. отправить текст в backend;
4. получить ответ;
5. озвучить ответ через Yandex SpeechKit TTS.

## Что нужно заполнить

В `docker-compose.yml` для сервиса `voice-gateway` задайте:

- `YC_FOLDER_ID`
- `YC_SPEECHKIT_API_KEY`

## Запуск

```bash
docker compose up -d --build
```

Если корпус документов ещё не индексирован:

```bash
docker compose exec backend python -m scripts.index_legal_corpus
curl -X POST http://localhost:8000/admin/reload -H "X-Admin-Key: change-me-123"
```

## Как тестировать

### Вариант 1. Запись с микрофона

1. Нажмите `Начать запись`.
2. Разрешите доступ к микрофону.
3. Произнесите вопрос.
4. Нажмите `Остановить`.
5. Нажмите `Отправить запись`.

### Вариант 2. Загрузка файла

Поддерживается загрузка короткого аудио, в первую очередь:

- WAV (предпочтительно для браузерного теста)
- OGG/Opus
- MP3

## Что происходит технически

- браузер записывает WAV;
- `voice-gateway` преобразует WAV в PCM16 и отправляет его в SpeechKit STT;
- распознанный текст уходит в backend как обычный вопрос;
- backend возвращает ответ и `tts_text`;
- `voice-gateway` синтезирует `tts_text` через SpeechKit TTS и отдаёт ссылку на аудио.

## Полезные ручки

- `GET /health`
- `GET /demo`
- `POST /calls/start`
- `POST /calls/{call_id}/turn`
- `POST /calls/{call_id}/recognize-and-answer`
- `GET /audio/{name}`
