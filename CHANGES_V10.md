# V10: голосовой шлюз + серверные голосовые API

## Что добавлено
- «голосовой шлюз» как отдельный сервис между телефонией и серверной частью.
- Конечные точки серверной голосовой связи:
  - `POST /голос/старт`
  - `ПОСТ /голос/поворот`
  - `POST /голос/хэндовер`
- Таблицы для истории звонков:
  - `voice_call_sessions`
  - `voice_call_turns`
  - `voice_call_events`
- `tts_text` как отдельный короткий текст под озвучивание.
- Реальный TTS-клиент под Yandex SpeechKit API v1 REST.
- Реальный STT-клиент для короткого аудио/демо под синхронный STT API Яндекса SpeechKit.
- Каркас `голосовой шлюз` для дальнейшего продвижения с SIP/Asterisk/FreeSWITCH.
- Скрипт генерации gRPC-stub'ов SpeechKit для потокового STT/TTS:
  `services/voice-gateway/scripts/generate_speechkit_stubs.sh`

## Что важно понимать
- В проекте добавлена ​​**рабочая голосовая основа**, но конечная SIP/RTP-интеграция зависит от выбранного телефона.
- Для живых звонков потоковую передачу SpeechKit STT v3 рекомендуется использовать через gRPC; для этого добавлен генератор stub'ов.
- Для локальных тестов и демо уже доступна версия:
  `аудиофайл -> STT -> серверная часть -> TTS`.
